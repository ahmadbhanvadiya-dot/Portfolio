# Home (single-page portfolio)

Mode: Experience. The work leads; chrome recedes. Build path: code-led (no image generation available).

Audience: recruiters, hackathon teammates, collaborators. Job: understand who Ahmad is, open a project, send an email.

## Direction contract

THESIS: A typeset index of real work, not a template of cards. The page reads like a well-set specimen sheet: one grotesk at several deliberate sizes, a quiet mono for facts, hairlines for structure. Refuses the dark-gradient hero, the card grid, the skill-badge wall.

OWN-WORLD: Warm off-white paper (#F6F4EF-ish) / near-black ink, warm graphite secondary, 1px hairlines at low contrast, one ultramarine accent used only for state (availability dot, active nav, focus, selection, link hover). Dark theme: warm charcoal, same roles. Schibsted Grotesk for all sans; Geist Mono for stacks and link metadata. Small radii (2-4px), no shadows except the preview frame.

STORY: Visitor learns name and intent in one sentence, sees five verified projects, three with screenshots of their live demos, scans stack by group, leaves with an email.

FIRST VIEWPORT: Nav strip (AB monogram + name left, five links + theme toggle right). Two-tone display sentence spanning ~10 columns: "Ahmad Bhanvadiya." in ink, "Building thoughtful digital experiences." in graphite. Description at 20px under it, left aligned, 52ch. Primary action "View selected work" (ink filled) + "Get in touch" text link. Bottom hairline row: availability with accent dot, GitHub / LinkedIn / Résumé in mono.

FORM: Pinned by the owner's brief; signature interaction is the Work index: hovering or focusing a row swaps a sticky preview frame (real demo screenshot) with a clip-path wipe; on mobile previews sit inline. seed: none (pinned) — "Background: warm off-white or subtle neutral. Primary text: near-black. ... Accent: one carefully selected color." / "Make the typography and whitespace do most of the work." / Hero: "Name: Ahmad Bhanvadiya. Primary headline direction: 'Building thoughtful digital experiences.' ... Include: Available for opportunities / collaborations. View selected work. Get in touch. GitHub and LinkedIn links."

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
